HackKit provides authentication, registration, participant profiles, permissions, event operations, and optional plugins. Applications own their pages and configuration. Core owns the domain rules and database model.

Start with a runnable workspace example. Use **minimal** for Core registration and basic administration. Use **full** when you also want Teams, Discord, email adapters, schedules, RSVP, and event passes.
